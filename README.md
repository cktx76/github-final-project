# Simple Interest Calculator

## Project Description
This project is a simple interest calculator written in Bash. It calculates the simple interest earned or paid based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal (P): Initial amount of money
- Rate (R): Annual interest rate in percentage
- Time (T): Time period in years

## Example
Principal: 1000
Rate: 5%
Time: 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## How to Use
1. Download or clone this repository.
2. Open a terminal.
3. Run `bash simple-interest.sh`.
4. Enter the principal, interest rate, and time period when prompted.
5. View the calculated simple interest.
